# 격물치지 (格物致知)

시험지·학습지 그림을 쉽게 그리는 곳 — 격물(수학·과학)과 치지(역사·지리·사회·윤리) 그림 편집기를 하나로 합친 웹앱 (베타 테스트판).

- 바로 쓰기: https://runedaeg.github.io/gyeokmulchiji/
- 첫 화면(대문)에서 과목을 고르면 격물·치지 편집기로 들어가요. 편집기 첫 화면 왼쪽 위 「‹ 격물치지」로 언제든 대문으로 돌아갈 수 있어요.
- 그림은 브라우저에만 저장되고 서버로 보내지 않아요.
- 업데이트 정리 (베타 1판과 비교): https://runedaeg.github.io/gyeokmulchiji/updates.html

## 최근 업데이트 — 베타 5 (2026-10-23)

- 학습지: 가로형·칸 너비·높이, 머리말·꼬리말·쪽 번호, 문제지+답지 함께 받기, 배점 합계·고르게 나누기, A형·B형, 빠른 정답표, 이 칸부터 새 쪽, 안내 글
- AI 풀이 초안 (내 Claude·ChatGPT 키): 보낼 내용을 먼저 확인하고, 받은 풀이를 검토·수정한 뒤 넣기
- 화면 아래 작업 탭, 범례 부품, 표 칸 합치기·정렬 안내선, 연표·확률·사람 그림 다듬기
- 내보내기 컬러·선화·회색, 저장하면서 복사, 출력 전 점검
- 중국어 병음 → 한자, 일본어 로마자 → 가나 입력 (입력기 없이)
- 보관함 폴더·여러 개 고르기·정렬
- 저작권 및 이용 안내, 과학 시험지형 그래프에서 기출 문항 번호·시험지 주소 제거
