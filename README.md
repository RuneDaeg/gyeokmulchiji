# 격물치지 (格物致知)

시험지·학습지 그림을 쉽게 그리는 곳 — 격물(수학·과학)과 치지(역사·지리·사회·윤리) 그림 편집기를 하나로 합친 웹앱 (베타 테스트판).

- 바로 쓰기: https://runedaeg.github.io/gyeokmulchiji/
- 첫 화면(대문)에서 과목을 고르면 격물·치지 편집기로 들어가요. 편집기 첫 화면 왼쪽 위 「‹ 격물치지」로 언제든 대문으로 돌아갈 수 있어요.
- 그림은 브라우저에만 저장되고 서버로 보내지 않아요.
- 업데이트 정리 (베타 1판과 비교): https://runedaeg.github.io/gyeokmulchiji/updates.html
